# 1. GitHub 계정과 로그인

수업 전에 세 가지를 준비합니다. 수업 당일 1교시 시작 전에 강사가 한 번 더 확인합니다.

!!! abstract "준비할 것"
    - [ ] GitHub 개인 계정을 만들고 로그인한다
    - [ ] 노트북 브라우저(크롬 또는 엣지)에서 github.com이 열리는지 확인한다
    - [ ] 휴대폰에 인증 앱을 설치한다 (7교시 2단계 인증 실습용)

## STEP 1. GitHub 계정 만들기

이미 계정이 있으면 STEP 2로 넘어갑니다.

1. 브라우저에서 [https://github.com](https://github.com)에 접속합니다.
2. 오른쪽 위 **Sign up**(가입) 버튼을 클릭합니다.
3. 순서대로 입력합니다.
    - **Email**: 회사 메일이나 개인 메일. 확인 메일을 받을 수 있는 주소여야 합니다.
    - **Password**: 15자 이상이거나, 8자 이상이면서 숫자와 소문자를 포함해야 합니다.
    - **Username**: GitHub에서 쓰는 아이디입니다. 영어, 숫자, 하이픈(-)만 쓸 수 있습니다. 수업 중에 팀원에게 알려 줄 이름이라 짧고 기억하기 쉽게 정합니다. 예: `kim-minho`
4. 사람인지 확인하는 퍼즐을 풀고 **Create account**를 클릭합니다.
5. 메일로 온 숫자 코드를 입력하면 가입이 끝납니다.

!!! warning "아이디는 나중에 바꾸기 번거롭습니다"
    Username은 리포지토리 주소에 들어갑니다(`github.com/아이디/리포지토리`). 회사 동료와 함께 쓰는 공간이니 본인을 알아볼 수 있는 이름을 추천합니다.

## STEP 2. 로그인 확인

1. [https://github.com](https://github.com)에 접속합니다.
2. 로그인 상태면 오른쪽 위에 **동그란 프로필 사진**이 보입니다.
3. 프로필 사진을 클릭하면 맨 위에 내 아이디가 보입니다. 이 아이디를 메모해 둡니다. 3교시와 4교시에 짝꿍과 팀원에게 알려 줘야 합니다.

```text
내 GitHub 아이디: ________________
```

## STEP 3. 회사망에서 접속 확인

회사 노트북은 보안 프로그램 때문에 일부 주소가 막혀 있을 수 있습니다. 아래 주소가 모두 열리는지 확인합니다.

| 주소 | 쓰는 곳 |
|---|---|
| `https://github.com` | 모든 실습 |
| `https://<내 아이디>.github.io` | 1교시부터 웹페이지 확인 (처음에는 404가 정상입니다) |
| `https://github.com/codespaces` | 7교시 터미널 실습 |

하나라도 열리지 않으면 수업 시작 전에 강사에게 알려 주세요.

## STEP 4. 휴대폰 인증 앱 설치

7교시에 계정 보안을 위해 2단계 인증을 켭니다. 휴대폰에 아래 앱 중 하나를 설치해 둡니다.

- Google Authenticator
- Microsoft Authenticator
- 이미 쓰고 있는 다른 인증 앱 (1Password, Authy 등)

!!! note "이미 2단계 인증이 켜져 있다면"
    GitHub가 2단계 인증 설정을 먼저 요구하는 경우가 있습니다. 이미 켜 두었다면 7교시에는 설정 상태만 확인하면 됩니다.

## 화면 언어

GitHub 화면은 **영어**입니다. 이 가이드는 메뉴와 버튼 이름을 화면 그대로 영어로 쓰고, 처음 나올 때 괄호로 뜻을 붙입니다. 예: **Commit changes**(변경 저장)

!!! info "화면이 조금 다를 수 있습니다"
    GitHub는 화면을 자주 개선합니다. 버튼 위치나 문구가 가이드와 조금 다르면, 같은 뜻의 버튼을 찾거나 강사에게 물어보세요.
