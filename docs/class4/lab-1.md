# 실습 4-1. Projects 보드 만들기

!!! abstract "이번 실습에서 할 것"
    - 내 계정에 개인 프로젝트 `내 연습 보드`를 만듭니다.
    - `lunch-practice`의 이슈를 프로젝트에 담습니다.
    - 프로젝트를 `lunch-practice` 리포지토리와 연결합니다.

**소요 시간** 약 7분  **실습 장소** 개인 연습 리포지토리 `lunch-practice`  **관련 교안** [4교시 교안](index.md#projects)

## 준비

- 2교시에 만든 이슈들이 `lunch-practice`에 있어야 합니다. **Issues** 탭에서 이슈가 3개 이상 보이면 됩니다.
- 이슈가 하나도 없다면 **Issues** → **New issue**로 제목만 있는 이슈를 3개 만들어 두세요. 예: `메뉴 목록 보기`, `예산으로 거르기`, `아무거나 골라 주기`.
- 브라우저 탭을 두 개 열어 둡니다. 하나는 `lunch-practice` 리포지토리, 하나는 새 프로젝트용입니다.

## STEP 1. 새 프로젝트 만들기

Projects는 리포지토리가 아니라 내 계정에 속합니다. 그래서 내 프로필에서 만듭니다.

1. GitHub 화면 오른쪽 위 **프로필 사진**을 클릭합니다.
2. 열린 메뉴에서 **Your projects**(내 프로젝트)를 클릭합니다.
    - 메뉴에 보이지 않으면 주소창에 직접 입력해도 됩니다. `아이디` 자리에 내 GitHub 아이디를 넣으세요.

    ```text
    https://github.com/아이디?tab=projects
    ```

3. 오른쪽 위 초록색 **New project**(새 프로젝트) 버튼을 클릭합니다.
4. 왼쪽 템플릿 목록에서 **Table**(표)을 고릅니다.
5. **Project name**(프로젝트 이름) 칸에 아래 이름을 입력합니다.

    ```text
    내 연습 보드
    ```

6. **Create project**(프로젝트 만들기)를 클릭합니다.

확인: 빈 표 화면이 열리고, 왼쪽 위에 `내 연습 보드`, 표 머리에 **Title**, **Assignees**, **Status** 칸이 보이면 성공입니다.

## STEP 2. 이슈 하나씩 담기 (Add item)

표 아래쪽 입력 칸으로 이슈를 하나씩 담을 수 있습니다.

1. 표 맨 아래 **+ Add item**(항목 추가)을 클릭합니다.
2. 입력 칸에 `#`을 입력합니다. 리포지토리 목록이 나타납니다.
3. 목록에서 **lunch-practice**를 클릭합니다.
4. `lunch-practice`의 이슈 목록이 나타나면 담을 이슈 하나를 클릭합니다.
5. 같은 방법으로 이슈를 하나 더 담습니다.

확인: 표에 이슈 2개가 한 줄씩 보이고, Status 칸이 비어 있거나 `Todo`로 보이면 성공입니다.

!!! note "Add item에 글자만 입력하면?"
    `#` 없이 글자만 입력하고 Enter를 누르면 **Draft**(초안) 항목이 생깁니다. 리포지토리에 없는 메모일 뿐 이슈가 아닙니다. 실수로 만들었다면 그 줄 오른쪽 **...** → **Delete from project**로 지우면 됩니다.

## STEP 3. 남은 이슈 한꺼번에 담기 (Add items from repository)

이슈가 많을 때는 하나씩 담는 대신 한꺼번에 담습니다.

1. 표 맨 아래 **+ Add item** 옆, 또는 프로젝트 오른쪽 위 **...** 메뉴를 엽니다.
2. **Add items from repository**(리포지토리에서 항목 추가)를 클릭합니다.
3. 리포지토리 선택 칸에서 **lunch-practice**를 고릅니다.
4. 아직 담지 않은 이슈들의 왼쪽 체크 칸을 모두 체크합니다. 맨 위 체크 칸을 누르면 전부 선택됩니다.
5. 아래 **Add selected items**(선택 항목 추가)를 클릭합니다.

확인: `lunch-practice`의 열린 이슈가 모두 표에 들어와 있으면 성공입니다.

## STEP 4. 리포지토리와 프로젝트 연결하기

프로젝트를 리포지토리에 연결해 두면 리포지토리의 **Projects** 탭에서 바로 찾아갈 수 있습니다.

1. `lunch-practice` 리포지토리 탭으로 이동합니다.
2. 위쪽 탭에서 **Projects**를 클릭합니다.
    - 탭이 보이지 않으면 화면 폭이 좁아서 **...** 안에 숨어 있는 것입니다. **...** → **Projects**를 누르세요.
3. **Link a project**(프로젝트 연결)를 클릭합니다.
4. 목록에서 **내 연습 보드**를 클릭합니다.

확인: `lunch-practice`의 **Projects** 탭에 `내 연습 보드`가 보이면 성공입니다. 이름을 누르면 프로젝트로 이동합니다.

!!! note "왜 연결하나요?"
    Projects는 계정에 속해 있어서, 연결하지 않으면 리포지토리 쪽에서는 프로젝트가 있는지 알 수 없습니다. 연결해 두면 리포지토리를 처음 보는 사람도 "이 일은 어디서 관리하지?"를 바로 찾을 수 있습니다. 4-3에서 팀 프로젝트도 같은 방법으로 팀 리포지토리에 연결합니다.

## STEP 5. 이슈 쪽에서 확인하기

1. `lunch-practice` → **Issues** → 프로젝트에 담은 이슈 하나를 엽니다.
2. 오른쪽 사이드바의 **Projects** 칸을 봅니다.

확인: **Projects** 칸에 `내 연습 보드`와 Status 값이 보이면 성공입니다. 이슈와 프로젝트가 서로 연결되어 있다는 뜻입니다.

## 성공하면

- [x] 내 계정에 `내 연습 보드` 프로젝트(Table)가 있다
- [x] `lunch-practice`의 열린 이슈가 모두 표에 들어 있다
- [x] `lunch-practice`의 **Projects** 탭에 `내 연습 보드`가 연결되어 있다
- [x] 이슈 오른쪽 사이드바에 `내 연습 보드`가 보인다

## 막히면

??? failure "Your projects 메뉴가 보이지 않습니다"
    프로필 메뉴 구성이 화면에 따라 조금 다릅니다. 주소창에 `https://github.com/아이디?tab=projects`를 직접 입력하세요. 또는 프로필 사진 → **Your profile** → 위쪽 **Projects** 탭으로 가도 됩니다.

??? failure "# 을 입력해도 lunch-practice가 목록에 없습니다"
    `#` 뒤에 `lunch`처럼 리포지토리 이름 앞부분을 입력하면 검색됩니다. 그래도 없다면 다른 계정으로 로그인했거나, 리포지토리 이름이 다를 수 있습니다. 리포지토리 주소가 `github.com/내아이디/lunch-practice`인지 확인하세요.

??? failure "Link a project 목록에 내 연습 보드가 없습니다"
    검색 칸에 `내 연습`을 입력해 보세요. 프로젝트를 방금 만들었다면 페이지를 새로고침(F5)한 뒤 다시 시도합니다.

??? failure "같은 이슈가 두 줄 들어갔습니다"
    같은 이슈는 한 프로젝트에 한 번만 들어갑니다. 두 줄로 보인다면 하나는 Draft 항목일 가능성이 큽니다. 제목 옆에 이슈 번호가 없는 줄의 **...** → **Delete from project**로 지우세요.
