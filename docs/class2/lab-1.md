# 실습 2-1. README 꾸미기

!!! abstract "이번 실습에서 할 것"
    - README.md 전체를 Markdown 문법으로 다시 씁니다. (제목, 그림, 굵게, 표, 체크박스, 링크)
    - Preview 탭으로 결과 모양을 확인하고 커밋합니다.
    - 리포지토리 첫 화면에서 README가 어떻게 보이는지 확인합니다.

**소요 시간** 약 5분  **실습 장소** 개인 연습 리포지토리 `lunch-practice`  **관련 교안** [2교시 교안](index.md#markdown)

## 준비

- 1교시 실습을 마친 `lunch-practice` 리포지토리 첫 화면(**Code** 탭)을 열어 둡니다.
- 지금 README에는 Starter에 들어 있던 제목과 한 줄 소개만 있습니다.
- 그림 파일 `docs/images/lunch.svg`와 회의록 `docs/01_킥오프_회의록.md`가 리포지토리에 있는지 **docs** 폴더를 열어 확인합니다.

## STEP 1. README 편집 화면 열기

1. 리포지토리 첫 화면의 파일 목록에서 **README.md**를 클릭합니다.
2. 오른쪽 위 **연필 아이콘**(Edit this file)을 클릭합니다.
3. 편집 칸 안을 한 번 클릭하고, 전체 선택 단축키(Windows ++ctrl+a++, Mac ++cmd+a++)를 누릅니다.
4. ++delete++ (또는 ++backspace++)를 눌러 기존 내용을 모두 지웁니다.

확인: 편집 칸이 비어 있습니다. (내 이름은 아래 완성본 맨 아래에 넣습니다.)

## STEP 2. 완성 README 붙여 넣기

1. 아래 코드 블록 오른쪽 위의 복사 아이콘을 눌러 전체를 복사합니다.
2. 빈 편집 칸에 붙여 넣습니다.
3. 맨 아래 `홍길동`을 **내 이름**으로 바꿉니다.

```markdown
# 점심 메뉴 추천 서비스

![점심](docs/images/lunch.svg)

팀원들이 점심 메뉴를 5분 안에 고를 수 있게 돕는 웹페이지입니다.

**목표: 메뉴 결정 시간 5분 이내**

## 메뉴 미리 보기

| 메뉴 | 가격 | 거리 |
|---|---|---|
| 김치찌개 | 9,500원 | 300m |
| 짜장면 | 8,000원 | 450m |
| 샐러드볼 | 10,500원 | 200m |

## 로드맵

- [x] 메뉴 카드로 보기
- [x] 예산, 거리로 거르기
- [x] 아무거나 골라 주기
- [x] 혼밥 가능 표시
- [ ] 만 원 넘는 메뉴 포함 여부 정하기
- [ ] 추천 개수 정하기 (하나 또는 여러 개)
- [ ] 팀원 투표로 정하기

## 이번에 하지 않는 것

- 식당 정보 자동 수집
- 로그인

## 관련 문서

- [현업 요청](docs/00_현업요청.md)
- [킥오프 회의록](docs/01_킥오프_회의록.md)
- [현행 업무](docs/02_현행_업무.md)

## 만든 사람

- 홍길동
```

확인: 편집 칸에 위 내용이 들어가 있고, 맨 아래가 내 이름입니다.

## STEP 3. 문법 하나씩 읽어 보기

붙여 넣은 README에 쓰인 문법을 하나씩 확인합니다. 편집 칸에서 해당 줄을 찾아보세요.

| 쓴 내용 | 문법 | 화면에서는 |
|---|---|---|
| `# 점심 메뉴 추천 서비스` | 샵 하나 + 띄어쓰기 = 가장 큰 제목 | 큰 제목과 아래 밑줄 |
| `![점심](docs/images/lunch.svg)` | 느낌표 + 대괄호(대체 글) + 괄호(그림 위치) = 그림 | 점심 그림 |
| `팀원들이 ... 웹페이지입니다.` | 아무 기호 없는 줄 = 문단 | 보통 글자 |
| `**목표: 메뉴 결정 시간 5분 이내**` | 별표 두 개로 감싸기 = 굵게 | **굵은 글자** |
| `## 메뉴 미리 보기` | 샵 둘 = 중간 제목 | 조금 작은 제목 |
| `| 메뉴 | 가격 | 거리 |` 와 `|---|---|---|` | 세로 막대로 칸 나누기, 둘째 줄은 머리글 경계 | 3열 표 |
| `- [x] 메뉴 카드로 보기` | 빼기 + 대괄호 안 x = 체크된 체크박스 | 체크 표시된 상자 |
| `- [ ] 팀원 투표로 정하기` | 빼기 + 대괄호 안 띄어쓰기 = 빈 체크박스 | 빈 상자 |
| `- 식당 정보 자동 수집` | 빼기 + 띄어쓰기 = 점 목록 | 점 목록 |
| `[킥오프 회의록](docs/01_킥오프_회의록.md)` | 대괄호(보이는 글) + 괄호(주소) = 링크 | 파란 글자 링크 |

!!! warning "자주 하는 실수"
    - `#` 뒤에 **띄어쓰기를 빼먹으면** 제목이 되지 않습니다. `#점심`은 그냥 글자로 보입니다.
    - 체크박스 `- [ ]`는 대괄호 안에 **띄어쓰기 한 칸**이 있어야 합니다. `- []`는 체크박스가 되지 않습니다.
    - 표 앞에는 **빈 줄**이 있어야 합니다. 바로 윗줄에 글이 붙어 있으면 표가 깨집니다.
    - 링크와 그림 주소의 파일 이름은 **글자 하나까지** 실제 파일과 같아야 합니다. `01_킥오프_회의록.md`의 밑줄(`_`)을 띄어쓰기로 바꾸면 링크가 깨집니다.

## STEP 4. Preview로 확인하기

1. 편집 칸 위쪽의 **Preview** 탭을 클릭합니다.
2. 위에서부터 아래로 훑으며 확인합니다.
    - 큰 제목 `점심 메뉴 추천 서비스`
    - 점심 그림
    - 굵은 글자 `목표: 메뉴 결정 시간 5분 이내`
    - 3열 표 (메뉴, 가격, 거리)
    - 체크박스 7개 (4개 체크, 3개 빈 상자)
    - 파란 링크 3개
3. 이상한 곳이 있으면 **Edit** 탭으로 돌아가 STEP 3의 표와 비교해 고친 뒤 다시 **Preview**를 누릅니다.

확인: Preview에서 그림, 표, 체크박스가 모두 모양을 갖춰 보입니다.

## STEP 5. 커밋하기

1. 오른쪽 위 초록색 **Commit changes...** 버튼을 클릭합니다.
2. **Commit message** 칸의 기본값을 지우고 아래처럼 씁니다.

    ```text
    README에 목표, 메뉴 표, 로드맵, 관련 문서 추가
    ```

3. **Extended description**에는 이유를 적습니다.

    ```text
    처음 온 사람이 README만 보고 프로젝트를 알 수 있게 정리
    ```

4. **Commit directly to the `main` branch**가 선택되어 있는지 확인하고 **Commit changes**를 클릭합니다.

확인: README.md 화면 위 회색 줄에 방금 쓴 커밋 메시지가 보입니다.

## STEP 6. 첫 화면과 링크 확인하기

1. 위쪽 리포지토리 이름 `lunch-practice`를 클릭해 첫 화면으로 갑니다.
2. 파일 목록 아래로 스크롤해 새 README가 펼쳐져 있는지 봅니다.
3. **관련 문서** 아래의 **킥오프 회의록** 링크를 클릭합니다.
4. 회의록 문서가 열리는지 확인한 뒤, 브라우저 뒤로 가기로 돌아옵니다.

확인: 리포지토리 첫 화면에 그림과 표가 있는 README가 보이고, 킥오프 회의록 링크가 회의록 파일로 연결됩니다.

!!! note "README의 체크박스는 클릭이 안 됩니다"
    README 같은 파일 속 체크박스는 보기 전용입니다. 체크하려면 파일을 편집해서 `[ ]`를 `[x]`로 바꾸고 커밋해야 합니다. 반면 **이슈 본문의 체크박스는 클릭으로 바로 체크**할 수 있습니다. 다음 실습부터 이슈에서 확인해 보세요.

## 막히면

??? failure "그림 자리에 깨진 그림 아이콘이나 '점심'이라는 글자만 보입니다"
    그림 주소가 실제 파일 위치와 다른 경우입니다. 정확히 `docs/images/lunch.svg`인지 확인합니다. 앞에 `/`를 붙이거나 `image`(s 빠짐)로 쓰면 그림을 못 찾습니다.

??? failure "표가 표로 안 보이고 세로 막대가 그대로 보입니다"
    두 가지를 확인합니다. 표 바로 위에 빈 줄이 있는지, 그리고 둘째 줄 `|---|---|---|`의 칸 수가 첫 줄(메뉴, 가격, 거리 3칸)과 같은지 확인합니다.

??? failure "체크박스가 [ ] 글자 그대로 보입니다"
    줄 앞의 빼기와 띄어쓰기(`- `)가 빠졌거나, 대괄호 안 띄어쓰기가 빠진 경우입니다. 정확히 `- [ ] ` 모양인지 확인합니다.

??? failure "링크를 누르면 404 This is not the web page you are looking for 가 나옵니다"
    링크 주소의 파일 이름이 실제와 다릅니다. **docs** 폴더에서 실제 파일 이름을 확인하고, 그 이름을 그대로 복사해 링크 괄호 안에 넣습니다.

??? failure "내 이름이 사라졌습니다"
    전체를 지우고 붙여 넣으면서 이름 줄을 `홍길동`으로 남긴 경우입니다. README를 다시 편집해 이름을 고치고 `README 만든 사람 이름 수정`으로 커밋합니다.
